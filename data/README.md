# 📊 SIH26033 — Dataset Documentation

This directory contains the datasets used for the AI/ML component of the SIH26033 solution.

The datasets are used for agricultural market analysis, feature engineering, demand/market-activity estimation, and model development.

> ⚠️ Raw datasets are preserved in their original format and must not be modified manually.

5. 🧹 Raw vs Processed Data
Raw Data

Location:

data/raw/

Raw files should remain unchanged.

They represent the original downloaded datasets.

Do not:

Rename columns manually
Delete rows manually
Change values manually
Overwrite files
Mix different datasets together

Any transformation must be performed by reproducible preprocessing scripts.

Processed Data

Location:

Processed datasets are generated by the preprocessing pipeline.

Possible outputs include:

data/processed/

6. 🔍 Data Quality Checks

Before using any dataset for ML, the preprocessing pipeline should check:

Number of records
Column names
Data types
Missing values
Duplicate records
Invalid dates
Invalid numerical values
State coverage
District coverage
Commodity/crop coverage
Year/date range
Temporal overlap between datasets

Large numbers of dropped records must never be hidden.

Any significant filtering or transformation must be documented.

7. 📅 Temporal Alignment

The datasets do not necessarily have the same temporal frequency.

For example:

Market data may contain daily observations.
Rainfall data contains daily observations.
Crop production data may contain yearly/seasonal observations.

Therefore, datasets must not be joined blindly.

Before creating the training dataset, the pipeline must determine:

Date range of each dataset
Available years
Common years
Common districts
Compatible crop/commodity mappings

Daily data may need to be aggregated to an appropriate time period before joining with annual or seasonal production data.

9. 🎯 Target Variable

The project does not currently have a large real-world dataset containing direct consumer purchase demand.

Therefore, the initial ML model must clearly distinguish between:

Actual observed demand
Market activity
Derived demand proxy
Synthetic/demo data
Model predictions

A market-based proxy must not be presented as actual consumer demand.

The target definition will be documented in:

docs/AI_ML.md

after the datasets have been audited.

10. 🧪 Synthetic Data

11. 🔐 Data & Security

No API keys, passwords, tokens, credentials, or other secrets should be stored in this directory.

If an API is used to download data:

Store credentials in environment variables.
Never commit API keys to Git.
Never place secrets inside source code.
Rotate exposed credentials immediately.

13. ⚠️ Important Data Disclaimer

These datasets are used for research, prototyping, analysis, and demonstration purposes within the SIH26033 project.

The availability, coverage, quality, and temporal range of the datasets may vary.

Model predictions depend on the quality and coverage of the available data and should not be interpreted as guaranteed real-world outcomes.

Any derived proxy variable must be explicitly identified as a proxy.
