# Data Directory — SIH26033 ML Pipeline

This directory manages raw, intermediate, and processed datasets utilized by the SIH26033 machine learning demand forecasting and route optimization pipelines.

## Directory Structure

```text
data/
├── raw/
│   ├── agmarknet/          # Mandi arrival volumes, wholesale prices, commodity reports
│   ├── crop_production/    # Historical yield, crop acreage, sowing/harvesting seasons
│   └── rainfall/           # Meteorological data (rainfall, temperature, climate indices)
├── processed/              # Aggregated, cleaned, and feature-engineered datasets ready for modeling
└── README.md               # Data documentation, provenance, and hygiene guidelines
```

## Datasets Overview

### 1. Raw Data (`data/raw/`)

- **`agmarknet/`**
  - **Source**: Agmarknet / Open Government Data (data.gov.in)
  - **Contents**: Daily market arrival volumes (quintals/kg), minimum, maximum, and modal wholesale prices across state mandis and APMCs.
  - **Important Rule**: Agmarknet arrivals represent market arrivals / supply throughput, not direct consumer demand. In models, document arrivals as a demand proxy.

- **`crop_production/`**
  - **Source**: Ministry of Agriculture & Farmers Welfare / Directorate of Economics and Statistics.
  - **Contents**: Historical crop production statistics by state, district, crop type, and season (Kharif, Rabi, Zaid).

- **`rainfall/`**
  - **Source**: India Meteorological Department (IMD) / weather APIs.
  - **Contents**: District-wise monthly, weekly, and daily rainfall observations, departures from normal, and drought/flood indicators.

### 2. Processed Data (`data/processed/`)

Contains transformed datasets generated by scripts in `ml/preprocessing/` and `ml/features/`.
- **Target Schema (Minimum Format)**:
  ```csv
  date,crop,region,demand_kg,modal_price,rainfall_mm,season,festival_flag
  ```
- **Storage Format**: Use standard formats like `.csv` or `.parquet` for feature tables.
- **Hygiene**:
  - Outliers and duplicates removed.
  - Chronological validation split maintained (no future data leakage).
  - All synthetic / demo data strictly labeled as `DEMO / SYNTHETIC DATA`.

## Provenance & Compliance

In adherence with `docs/RESEARCH_AND_DATA.md` and `agent/MASTER_AGENT_INSTRUCTIONS.md`:
- Never commit private credentials or API keys with data fetchers.
- Do not commit large binary or raw CSV datasets (> 50MB) to Git version control.
- Clearly document data source URLs, collection timestamps, and transformation steps.
