# UI/UX Requirements — SIH26033 Solution

## 1. UX Principle

The platform must look like one coherent product while providing role-specific experiences.

## 2. Farmer App

### Dashboard
Show:
- today's active listings
- incoming orders
- available earnings
- crop demand alerts

### Add Produce
Fields:
- crop
- variety
- quantity
- quality
- price
- availability
- location

### Demand Insight
Show:
- current demand
- predicted demand
- simple trend graph
- explanation

### Orders
Show clear status:
`Placed → Confirmed → Pickup → In Transit → Delivered → Settled`

## 3. FPO Dashboard

- organization summary
- member farmers
- aggregated inventory
- RFQs
- accepted orders
- logistics

## 4. Consumer Marketplace

- search
- crop/category filters
- location
- price
- quality
- seller/FPO
- quantity

## 5. Bulk Buyer Portal

Primary screen:

```text
Create RFQ
Crop
Quantity
Required By
Delivery Location
Target Price (optional)

[Find Supply]
```

Results should show match score and offers.

## 6. Logistics Dashboard

- today's routes
- vehicle capacity
- stops
- route map
- ETA
- shipment status

## 7. Admin Dashboard

Cards:
- active farmers/FPOs
- active buyers
- active orders
- listed quantity
- forecasted demand

Charts:
- demand trend
- price trend
- regional supply
- logistics efficiency

## 8. Accessibility

For the prototype:
- Hindi + English
- readable typography
- large primary actions
- mobile responsive
- low-bandwidth-conscious UI

Voice, IVR and feature-phone flows are future/optional unless the team has enough time.
